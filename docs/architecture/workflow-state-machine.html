Why is there no SYNCING state?

This is an intentional public API contract in the source. While execution is in progress, the request remains READY_TO_SYNC / APPROVED (or SYNC_FAILED during recovery); the actual PENDING / RUNNING / retry / batch-checkpoint state is persisted by SyncJob and SyncBatch.
